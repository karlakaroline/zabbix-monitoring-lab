# Security Guidelines

This repository is intended for public demonstration and lab use.

Do not commit:

- passwords, API tokens or authentication headers;
- production hostnames or internal DNS names;
- real customer or organization names;
- private IP addressing from production environments;
- internal URLs, VPN endpoints or management interfaces;
- screenshots that reveal usernames, hostnames, ticket IDs or customer branding;
- certificates, private keys or configuration backups.

Use fictional lab names and documentation-only networks where possible.

Recommended documentation address ranges include:

- `192.0.2.0/24`
- `198.51.100.0/24`
- `203.0.113.0/24`

Before publishing a new example, review the full file and any image separately.
